
# 📝 To-Do List App (Python)

A simple command-line To-Do List application built with Python.

## Features

- Add tasks
- View tasks
- Delete tasks
- Automatically saves tasks to a file

## Technologies

- Python 3

## How to Run

```bash
python todo.py
```
